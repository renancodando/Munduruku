# Capítulo 3 — Palavras têm partes

Até agora você treinou os olhos. A partir daqui começa a parte que realmente transforma a leitura: perceber que muitas formas não precisam ser memorizadas como blocos indivisíveis.

Em Mundurukú, nomes, verbos e posposições podem ocorrer com marcas de pessoa. Na análise de Dioney Gomes, essas marcas pessoais são **clíticos**, e não simplesmente prefixos comuns. Isso será aprofundado mais tarde. Por enquanto, você precisa aprender a reconhecer o padrão.

---

## 1. Seis marcadores que aparecerão muitas vezes

Para posse nominal, objeto de posposição e determinados argumentos verbais, Gomes apresenta o seguinte conjunto:

| Pessoa | Marcador | Ideia aproximada em contexto possessivo |
|---|---:|---|
| 1ª singular | `o` | meu/minha |
| 1ª plural inclusiva | `wuy` | nosso/nossa, incluindo o interlocutor |
| 1ª plural exclusiva | `oce` | nosso/nossa, sem incluir o interlocutor |
| 2ª singular | `e` | teu/tua, seu/sua de você |
| 2ª plural | `ey` | de vocês |
| correferencial | `je` | de si mesmo, conforme a construção |

Não trate a última coluna como tradução automática. Ela serve apenas para você entender a relação de pessoa no começo do estudo.

---

## 2. Inclusivo e exclusivo

O português usa **nós** para situações diferentes:

> eu + você

> eu + outra pessoa, mas não você

Mundurukú distingue essas relações no sistema de pessoa.

`wuy` → primeira pessoa plural **inclusiva**

`oce` → primeira pessoa plural **exclusiva**

### Exercício

Qual marcador você procuraria primeiro em uma forma que indicasse:

1. "nosso", incluindo a pessoa com quem se fala? ______
2. "nosso", excluindo a pessoa com quem se fala? ______
3. primeira pessoa singular? ______
4. segunda pessoa singular? ______
5. segunda pessoa plural? ______

### Respostas

1. `wuy`
2. `oce`
3. `o`
4. `e`
5. `ey`

---

## 3. Não confunda marcador com palavra independente

Uma armadilha seria decorar:

`o = meu`

`e = teu`

E parar aí.

Isso seria insuficiente. Esses elementos participam de construções morfológicas. O resultado visível pode sofrer ajustes conforme a classe da palavra e o elemento que vem depois.

Por isso, vamos usar uma notação didática:

`MARCADOR = BASE`

O sinal `=` nesta apostila indica que estamos mostrando uma ligação clítica na análise, não que você deva inserir literalmente o caractere `=` na escrita normal.

Exemplo abstrato:

`o = BASE`

A forma real resultante depende da base e de sua classe.

---

## 4. Um primeiro paradigma com nomes

Crofts e Gomes usam palavras como `dao` "perna", `a'õ` "voz", `ba` "braço" e `kobe` "canoa" para mostrar como a marcação pessoal funciona.

Observe somente a coluna de `dao`:

| Pessoa | Forma apresentada na fonte |
|---|---|
| 1ª singular | `odao` |
| 2ª singular | `edao` |
| 3ª singular | `tao` |
| correferencial | `jedao` |
| 1ª plural exclusiva | `ocedao` |
| 1ª plural inclusiva | `wuydao` |
| 2ª plural | `eydao` |

Agora não tente aprender a terceira pessoa nem explicar `tao`. O objetivo é reconhecer que várias formas compartilham uma base relacionada a `dao`.

Marque mentalmente:

`o + dao`

`e + dao`

`je + dao`

`oce + dao`

`wuy + dao`

`ey + dao`

Você já não precisa memorizar seis palavras independentes.

---

## 5. Reconhecimento de base

### Exercício A

Sublinhe mentalmente a parte repetida:

- `odao`
- `edao`
- `jedao`
- `ocedao`
- `wuydao`
- `eydao`

Qual sequência aparece em todas? __________

Resposta: `dao`.

### Exercício B

Sem consultar a tabela, reconstrua:

1. `o` + `dao` → __________
2. `e` + `dao` → __________
3. `wuy` + `dao` → __________
4. `oce` + `dao` → __________
5. `ey` + `dao` → __________
6. `je` + `dao` → __________

Respostas:

1. `odao`
2. `edao`
3. `wuydao`
4. `ocedao`
5. `eydao`
6. `jedao`

## 6. Nem toda base se comporta como `dao`

Este é um ponto decisivo.

Se todas as palavras aceitassem o marcador exatamente da mesma maneira, a gramática seria muito mais simples. Mas as fontes descrevem classes diferentes de nomes e ajustes morfofonológicos.

Compare formas apresentadas com `kobe` "canoa":

| Pessoa | Forma |
|---|---|
| 1ª singular | `wekobe` |
| 2ª singular | `ekobe` |
| correferencial | `jekobe` |
| 1ª plural exclusiva | `ocekobe` |
| 1ª plural inclusiva | `wuyekobe` |
| 2ª plural | `eyekobe` |

Veja a diferença:

`o + dao` → `odao`

mas, na classe de `kobe`, a primeira pessoa singular aparece como:

`wekobe`

Isso acontece porque os nomes alienáveis apresentam uma marca específica e combinações morfofonológicas. Você estudará isso com calma no próximo capítulo.

---

## 7. Como ler uma palavra longa sem pânico

Quando encontrar uma forma longa:

1. procure uma base que você já conhece;
2. veja se o começo lembra um marcador pessoal;
3. não force uma segmentação;
4. compare com outras formas do mesmo paradigma;
5. só então consulte a análise gramatical.

Exemplo:

`wuydao`

Você já reconhece:

`wuy` + `dao`

Mesmo antes de dominar toda a teoria, a palavra deixou de ser um bloco opaco.

---

## 8. Cartões de análise

Faça cartões diferentes de cartões de vocabulário.

### Frente

`ocedao`

### Verso

- base reconhecida: `dao`
- marcador reconhecido: `oce`
- pessoa: 1ª plural exclusiva
- campo semântico da base na fonte: perna

Outro:

### Frente

`wuydao`

### Verso

- base: `dao`
- marcador: `wuy`
- pessoa: 1ª plural inclusiva

Não escreva apenas "nossa perna". O objetivo é aprender a **analisar**, não apenas traduzir.

---

## 9. Teste cumulativo

Sem olhar:

1. Qual marcador corresponde à primeira pessoa singular?
2. Qual é a diferença entre `wuy` e `oce`?
3. Qual base aparece em `odao`, `edao`, `wuydao` e `ocedao`?
4. Por que `wekobe` é importante para o estudo?
5. O sinal `=` usado nas análises deve ser digitado na escrita normal?

### Gabarito

1. `o`.
2. `wuy` é inclusivo; `oce` é exclusivo.
3. `dao`.
4. Porque mostra que outra classe nominal não combina os elementos exatamente como `dao`.
5. Não. É uma notação analítica.

---

## 10. Meta de domínio

Avance somente quando você conseguir:

- reconhecer `o`, `e`, `wuy`, `oce`, `ey` e `je`;
- explicar inclusivo × exclusivo sem olhar;
- localizar `dao` dentro das formas flexionadas;
- entender por que não devemos criar uma regra única para todos os nomes;
- analisar uma forma antes de traduzi-la.

Dioney Moreira Gomes, *Estudo morfológico e sintático da língua Mundurukú (Tupí)*, 2006, capítulo 1. Os paradigmas retomam dados discutidos a partir de Crofts e são usados aqui com finalidade didática.
