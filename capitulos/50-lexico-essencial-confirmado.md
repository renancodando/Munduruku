# Capítulo 50 — Léxico essencial confirmado

Este não é um “vocabulário inventado para completar página”. Ele reúne apenas formas que já apareceram nos capítulos com apoio nas fontes utilizadas. O léxico crescerá por consulta documentada, não por analogia.

## 13. Morfemas importantes

| Forma | Função estudada |
|---|---|

| `-yũ` | plural |
| `-'in` | partitivo / individualizador |
| `-'ũm` | privativo |
| `-buk` | abandonado / não mais pertencente em usos descritos |

---

## 14. Como ampliar este léxico

Para cada nova entrada, registre:

- forma exata;
- sentido no contexto;
- classe;
- morfologia;
- variante ortográfica;
- exemplo curto ou referência;
- fonte;
- status de confirmação.

Um léxico menor e confiável é muito mais útil que milhares de equivalências sem fonte.
