# Capítulo 45 — Projeto final de leitura

Este projeto verifica se você consegue ler um texto novo de forma autônoma. Escolha um texto Mundurukú cuja origem seja conhecida e cuja grafia possa ser identificada.

O objetivo não é terminar rápido. É produzir uma análise que você consiga defender.

---

## 1. Escolha do texto

O texto deve:

- ter fonte identificável;
- ter tamanho compatível com seu nível;
- não ser um trecho que você já memorizou;
- permitir consulta a dicionário e gramática;
- preferencialmente possuir tradução ou comentário confiável para conferência posterior.

## 12. Critério de aprovação

O projeto está concluído quando você consegue:

- explicar a estrutura geral do texto;
- acompanhar os principais participantes;
- analisar morfologicamente formas centrais;
- justificar as principais relações entre orações;
- usar dicionário de forma seletiva;
- separar certeza de hipótese;
- produzir uma tradução de controle sem depender dela durante a primeira leitura.

Compreensão avançada não significa eliminar toda dúvida. Significa saber **onde a dúvida está e como investigá-la**.
