# Capítulo 46 — Projeto final de escrita

Este projeto verifica se você consegue transformar conhecimento gramatical em produção escrita controlada e revisável.

O objetivo não é escrever o texto mais longo possível. É escrever um texto no qual cada estrutura importante possa ser explicada.

---

## 1. Escolha do gênero

Escolha um:

- narrativa curta;
- descrição;
- relato;
- resumo de texto já estudado;
- explicação;
- comparação;
- diário;
- texto literário controlado.

Evite começar por um gênero que exija estruturas que você ainda não estudou.

## 6. Revisão morfológica

Para cada forma complexa, verifique:

- [ ] base correta
- [ ] classe correta
- [ ] pessoa correta
- [ ] inclusivo/exclusivo correto
- [ ] relacional correto
- [ ] aspecto correto
- [ ] reduplicação documentada
- [ ] causativo/nominalizador correto
- [ ] plural/partitivo correto

Corrija a segunda versão.

---

## 7. Revisão sintática

Verifique:

- [ ] transitividade
- [ ] identificação dos argumentos
- [ ] relação objeto-verbo
- [ ] sintagmas posposicionais
- [ ] conjunções
- [ ] ordem motivada
- [ ] incorporação, se houver

---

## 8. Revisão discursiva

Verifique:

- [ ] participantes podem ser acompanhados
- [ ] demonstrativos possuem referente claro
- [ ] contraste possui alternativa real
- [ ] restrição possui conjunto de alternativas
- [ ] inclusão possui contexto anterior
- [ ] negação possui escopo claro
- [ ] grau de certeza corresponde à intenção

---

## 9. Revisão ortográfica

Leia caractere por caractere:

- [ ] til
- [ ] apóstrofo
- [ ] grafemas corretos
- [ ] variantes condicionadas
- [ ] separação de palavras
- [ ] sistema ortográfico consistente

## 12. Critério de conclusão

O projeto está aprovado quando:

- o texto usa apenas estruturas justificáveis;
- os erros detectados foram corrigidos por categoria;
- a ortografia é consistente;
- os participantes podem ser acompanhados;
- você sabe quais partes ainda têm incerteza;
- a versão final não é mera tradução palavra por palavra de um texto português.
