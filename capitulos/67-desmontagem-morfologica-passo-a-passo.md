# Capítulo 67 — Desmontagem morfológica passo a passo

Este capítulo reúne o método que será usado para analisar palavras longas sem adivinhar cortes.

## 1. Regra principal

Uma sequência visível não vira morfema só porque parece repetida.

Todo corte precisa ser sustentado por:

- paradigma;
- comparação entre formas;
- descrição gramatical;
- comportamento sintático;
- ou análise explícita de fonte confiável.

---

## 2. Camada 1 — copie sem alterar

**Forma original:** ____________________

Registre exatamente:

- letras;
- apóstrofos;
- nasalidade;
- hífens, se a fonte usar;
- espaços;
- variante ortográfica.

Nunca normalize antes de analisar.

---

## 3. Camada 2 — procure material conhecido

Marque apenas sequências já confirmadas em outros paradigmas.

Exemplos de elementos estudados:

- marcadores pessoais;
- `mu- / muy-`;
- `do- / duju-`;
- `-m`;
- `-ap`;
- `-yũ`;
- `-'in`;
- `-'ũm`;
- `-buk`.

Reconhecer uma sequência ainda não prova que ela tenha a mesma função na nova palavra.

---

## 4. Camada 3 — hipótese de segmentação

Escreva uma primeira hipótese:

`___ | ___ | ___`

Abaixo, classifique cada pedaço:

| Segmento | Função proposta | Evidência |
|---|---|---|
| | | |
| | | |
| | | |

Use “incerto” quando necessário.

---

## 5. Camada 4 — teste por comparação

Procure outra palavra que contenha:

- a mesma raiz sem um afixo;
- o mesmo afixo com outra raiz;
- outra pessoa do mesmo paradigma;
- outra forma aspectual;
- variante com função equivalente.

Se nenhuma comparação existir, reduza a confiança da análise.

---

## 6. Camada 5 — função da palavra inteira

Antes de fechar a análise, identifique:

- nome ou verbo?;
- argumento ou predicado?;
- possui complemento?;
- recebe marca pessoal?;
- participa de relação possessiva?;
- modifica outra expressão?

A palavra inteira precisa fazer sentido na sentença.

---

## 7. Camada 6 — glosa

Somente depois, escreva uma glosa morfológica.

Linha 1 — forma original.

Linha 2 — segmentação.

Linha 3 — função de cada segmento.

Linha 4 — tradução contextual.

A tradução não deve ser usada para inventar a segmentação.

---

## 8. Grau de confiança

Classifique:

### A — confirmado

A fonte fornece a análise ou o paradigma é claro.

### B — fortemente sustentado

Há várias comparações consistentes.

### C — hipótese

Há indícios, mas falta confirmação.

### D — desconhecido

Não há evidência suficiente.

Essa escala deve aparecer em análises avançadas da apostila.

---

## 9. Exercício com forma conhecida

Use o verbo-base `'at` e os elementos causativos já estudados apenas para revisar o procedimento.

Não crie uma combinação nova automaticamente.

Localize em uma fonte um exemplo confirmado e preencha:

**Forma:** ____________________

**Raiz:** ____________________

**Causativo:** ____________________

**Outros elementos:** ____________________

**Função geral:** ____________________

**Confiança:** ____________________

---

## 10. Erros proibidos

Evite:

- cortar pela quantidade de sílabas;
- tratar qualquer sequência repetida como afixo;
- traduzir cada pedaço antes de confirmar sua função;
- copiar uma análise de outra palavra sem testar;
- apagar variantes gráficas.

---

## 11. Meta de domínio

Você conclui quando consegue:

- copiar uma forma sem normalizá-la;
- formular segmentações como hipóteses;
- justificar cortes por paradigmas;
- atribuir grau de confiança;
- separar glosa, função e tradução.
