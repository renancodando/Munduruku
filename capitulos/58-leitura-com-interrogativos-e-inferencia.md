# Capítulo 58 — Leitura com interrogativos e inferência

Este capítulo usa interrogativos já confirmados para treinar compreensão de textos sem depender de tradução completa.

## 1. Formas da unidade

| Forma | Valor geral estudado |
|---|---|
| `abu` | quem? |
| `ajo` | o que? |
| `poce / apoce` | onde? |
| `poma / apoma` | para onde? |
| `podi / apodi` | por onde? |
| `pẽn / apẽn` | como? |
| `pugun` | quando? em referência futura na análise estudada |
| `puje` | quando? em referência passada em uso interrogativo descrito |
| `peburu` | quantos? |
| `pebit` | quanto? em dimensão |

Esses valores são pontos de partida. A interpretação final depende da construção e do contexto.

---

## 2. Perguntar para compreender

Quando ler um texto curto, faça perguntas antes de traduzir:

- Quem participa?
- O que acontece?
- Onde?
- Para onde?
- Por onde?
- Como?
- Quando?
- Quantos?

No início, escreva essas perguntas em português. Depois substitua gradualmente pelos interrogativos Mundurukú.

---

## 3. Prancha visual de perguntas

Crie dez pequenos quadros:

1. pessoa desconhecida → `abu`
2. objeto desconhecido → `ajo`
3. ponto no mapa → `poce / apoce`
4. seta chegando a destino → `poma / apoma`
5. caminho traçado → `podi / apodi`
6. modo de realização → `pẽn / apẽn`
7. calendário futuro → `pugun`
8. evento passado → `puje`
9. conjunto de objetos → `peburu`
10. dimensão de objeto → `pebit`

A imagem deve sugerir a pergunta sem português escrito.

## 5. Leitura por perguntas

Pegue um parágrafo curto de fonte confiável.

Sem traduzir, complete:

**abu?** → ____________________

**ajo?** → ____________________

**poce / apoce?** → ____________________

**pẽn / apẽn?** → ____________________

Nem toda pergunta terá resposta no texto. Marque “não informado” quando for o caso.

Isso é importante: compreensão inclui perceber o que o texto **não diz**.

---

## 6. Inferência controlada

Se uma resposta não aparece explicitamente, marque:

- explícita;
- inferida com forte evidência;
- hipótese fraca;
- não é possível determinar.

Nunca transforme inferência em fato sem perceber.

---

## 8. Quantidade e dimensão

Não confunda:

- quantos elementos existem;
- quanto mede ou qual é a dimensão de algo.

Use:

`peburu` para o primeiro tipo de pergunta estudado.

`pebit` para o segundo tipo.

Crie duas imagens: cinco objetos pequenos e um único objeto comprido. Associe o interrogativo adequado a cada uma.

---

## 9. Perguntas como teste de leitura

Depois de qualquer texto, produza pelo menos cinco perguntas de compreensão.

No nível avançado, evite perguntas que possam ser respondidas copiando uma palavra. Prefira:

- relações entre participantes;
- sequência temporal;
- causa;
- mudança de lugar;
- inferência;
- contraste;
- informação implícita.

---

## 10. Redução do português

Faça três rodadas.

### Rodada 1

Pergunta em português + interrogativo Mundurukú.

### Rodada 2

Somente interrogativo Mundurukú + ícone.

### Rodada 3

Somente interrogativo Mundurukú.

A meta é recuperar a função diretamente da forma.

---

## 11. Meta de domínio

Você conclui esta unidade quando consegue:

- reconhecer rapidamente os interrogativos estudados;
- escolher a pergunta adequada para cada tipo de informação;
- usar perguntas para compreender um texto antes de traduzi-lo;
- distinguir informação explícita de inferência;
- responder a perguntas simples com português mínimo.
