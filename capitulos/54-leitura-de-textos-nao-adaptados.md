# Capítulo 54 — Leitura de textos não adaptados

Este capítulo marca a passagem da leitura didática para a leitura real. Um texto não adaptado não foi escrito para ensinar você. Ele pode conter formas raras, grafia diferente, estruturas longas, vocabulário desconhecido e referências culturais que não aparecem em exercícios escolares.

A meta não é entender 100% na primeira leitura. A meta é construir uma interpretação confiável sem depender de tradução linha por linha.

## 1. Primeira leitura: não pare

Leia o texto inteiro uma vez sem dicionário.

Marque apenas:

- palavras que você reconhece;
- marcas gramaticais familiares;
- nomes repetidos;
- elementos que parecem ligar orações;
- trechos totalmente opacos.

Não consulte nada ainda.

---

## 2. Segunda leitura: estrutura

Agora divida o texto em unidades menores.

Para cada sentença, registre:

| Elemento | O que encontrei |
|---|---|
| possível núcleo verbal | |
| participantes explícitos | |
| marcas pessoais | |
| posposições | |
| partículas | |
| conectores | |
| formas desconhecidas | |

Essa tabela impede que você trate toda palavra desconhecida como igualmente importante.

---

## 3. Terceira leitura: vocabulário prioritário

Pesquise primeiro as palavras que parecem essenciais para a ação ou para a relação entre participantes.

Deixe para depois:

- detalhes descritivos não essenciais;
- formas cuja função já pode ser inferida;
- palavras que aparecem apenas uma vez e não bloqueiam o sentido global.

O bom leitor não consulta tudo. Ele consulta o que muda a interpretação.

---

## 4. Grafia diferente não significa palavra diferente

Textos de épocas e autores distintos podem empregar convenções diferentes. Quando encontrar uma forma que parece conhecida, mas está escrita de outro modo:

1. copie exatamente a forma da fonte;
2. registre a data da publicação;
3. compare com a grafia que você estudou;
4. verifique se a diferença é ortográfica ou lexical;
5. não “corrija” o texto original.

Mantenha sempre duas colunas:

| Forma na fonte | Forma de referência atual/da apostila |
|---|---|
| | |

Só preencha a segunda coluna quando houver confirmação.

---

## 5. Leitura por hipóteses

Em vez de buscar uma tradução definitiva cedo demais, trabalhe com hipóteses.

**Hipótese A:** ____________________

**Evidência:** ____________________

**O que contradiz:** ____________________

**Confiança:** baixa / média / alta

Quando uma nova sentença aparecer, revise a hipótese.

Esse método é especialmente útil quando um participante não está nomeado explicitamente.

---

## 6. O contexto vem antes do dicionário

Antes de pesquisar uma forma, tente responder:

- ela parece nome, verbo ou elemento funcional?
- está próxima de qual palavra?
- aparece mais de uma vez?
- recebe marca pessoal?
- participa de construção possessiva?
- ocorre em posição semelhante a outra forma conhecida?

Depois consulte o dicionário.

O dicionário confirma ou corrige uma análise. Ele não substitui a análise.

---

## 7. Registro de descoberta

Toda palavra nova encontrada em leitura real deve entrar em uma ficha:

**Forma:** ____________________

**Fonte:** ____________________

**Trecho:** ____________________

**Significado no contexto:** ____________________

**Classe/função:** ____________________

**Morfologia:** ____________________

**Outra ocorrência encontrada:** ____________________

**Grau de certeza:** ____________________

Uma palavra não deve entrar no léxico principal com base em uma única suposição.

---

## 8. Tradução apenas no fim

Depois de analisar o texto, produza duas versões:

### Versão 1 — sentido global

Explique em português o que o texto comunica, sem tentar copiar sua estrutura.

### Versão 2 — tradução analítica

Agora tente manter mais perto a organização da fonte.

Compare as duas. Se elas divergem muito, volte à análise.

---

## 9. Página ilustrada sugerida

A dupla de páginas desta unidade deve mostrar um texto curto não adaptado no centro, com quatro camadas transparentes sobrepostas:

1. reconhecimento lexical;
2. morfologia;
3. referentes;
4. interpretação.

O estudante deve conseguir olhar a mesma passagem de quatro maneiras diferentes.

---

## 10. Meta de domínio

Você conclui esta unidade quando consegue:

- ler um texto curto não adaptado sem interromper a primeira leitura;
- identificar quais palavras realmente precisam ser consultadas;
- comparar grafias sem alterar a fonte;
- formular e revisar hipóteses;
- produzir primeiro o sentido global e só depois uma tradução analítica.
